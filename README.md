# 나만의 메모장

Flask 와 MongoDB 로 만든 메모장. nginx 뒤에서 gunicorn 으로 돌아간다.

> **모든 메모는 누구나 읽을 수 있는 공개 게시판입니다.**
> 계정이 없으므로 목록·검색·태그·그래프가 전부 전체 공개입니다. 남이 내 메모를
> 고치거나 지우지 못하게 막을 뿐, 읽는 것은 막지 않습니다. 남에게 보이면 안 되는
> 내용은 **잠금 메모**로 쓰세요. 그것만 서버도 읽지 못합니다.

## 기능

**메모끼리 잇기** — 내용에 `[[다른 메모 제목]]` 을 적으면 그 메모로 이어진다.
백링크와 아직 쓰지 않은 링크를 보여 주고, 연결 관계를 그래프로 그린다.
`Ctrl+K` 로 제목만 쳐서 이동한다.

**기록 남기기** — 고칠 때마다 이력이 쌓이고 무엇이 바뀌었는지 줄 단위로
비교한다. 예전 내용으로 되돌릴 수 있다. 활동 히트맵과 연속 작성 일수를 센다.

**비밀 지키기** — 브라우저에서 암호화하는 잠금 메모, 읽기 전용 공유 링크,
한 번 읽으면 사라지는 메모, 지정한 날짜에 열리는 타임캡슐.

**기본** — 작성·수정·삭제·좋아요·고정, 태그 분류, 검색, 정렬, 마크다운 렌더링,
다크 모드, 페이지네이션, 초안 자동 저장, 삭제 실행 취소. 키보드만으로 조작할 수 있다.

동작 원리와 그렇게 만든 이유는 [docs/DESIGN.md](docs/DESIGN.md) 에 적었다.

## 구조

| 경로 | 내용 |
|---|---|
| `app.py`, `wsgi.py` | 개발 서버 실행용, gunicorn 진입점 |
| `memo/` | 애플리케이션 패키지. 팩토리, 설정, DB, 도메인 로직, 라우트 |
| `templates/`, `static/` | 마크업과 CSS·JS. 실행되는 인라인 스크립트가 없어 CSP 를 적용할 수 있다 |
| `tests/` | pytest (단위 + 통합) |
| `deploy/`, `scripts/` | systemd 유닛, nginx 설정, 백업·복구·감시 |

## 로컬 실행

Python 3.10 이상과 `localhost:27017` 에 떠 있는 MongoDB 가 필요하다.

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env
python app.py                   # http://localhost:5000
```

## 테스트

테스트도 MongoDB 에 실제로 붙는다. 임시 DB 를 만들어 쓰고 끝나면 지운다.
커버리지 85% 미만이면 실패한다.

```bash
pytest
ruff check .
```

nginx 뒤에 gunicorn 을 두고 앱 포트는 외부에 열지 않는다. 절차와 운영 명령은

## 유의 사항

- 소유 토큰은 브라우저에만 저장된다. 기기를 바꾸거나 저장소를 지우면 그 메모를
  더는 고칠 수 없고, 내보내기 기능은 아직 없다.
- 잠금 메모는 비밀번호를 어디에도 저장하지 않는다. 잊으면 끝이며, 검색되지 않고
  나중에 고칠 수도 없다. 암호문 길이 때문에 600자까지만 쓸 수 있다.
- 관리자 토큰을 브라우저에 넣으면 평문으로 보관된다. 계정이 없는 구조의 절충이다.
- 타임캡슐은 서버가 평문을 갖고 있고 소유자는 언제든 해제할 수 있다. 남을 막는
  잠금이 아니라 스스로 정한 때까지 열지 않겠다는 약속에 가깝다.
- 같은 제목의 메모를 막지 않는다. `[[제목]]` 링크가 여럿에 걸리면 그중 하나로 간다.
- 검색은 정규식이라 인덱스를 타지 않는다. 수만 건을 넘으면 다른 방식이 필요하다.
